Construo os sistemas internos de uma distribuidora de material elétrico: do banco Oracle do ERP até o app que roda no coletor do armazém.

Trabalho na Elétrica Bahiana, que tem lojas em Salvador, Lauro de Freitas e Aracaju. Faço a ponte entre o que vendas, logística e RH precisam e o que o ERP permite, com Python, TypeScript e SQL.

Projetos na Elétrica Bahiana

Código privado da empresa, feito em equipe. Aqui fica o que cada sistema resolve.

Portal interno e API

Um só endereço onde vendas, logística, compras e RH abrem as ferramentas do dia a dia. Front-end em React com carregamento por tela, API em FastAPI ligada ao Oracle do ERP e um worker separado para as tarefas longas. As permissões por setor e por pessoa são geridas pela própria TI, sem deploy.

  • React
  • TypeScript
  • Vite
  • Tailwind
  • FastAPI
  • Oracle

CableControl

Estoque de cabos elétricos por endereço. Cada bobina e cada ponta tem torre e posição. O corte para o pedido é feito em um passo, e a sobra herda o endereço da peça de origem. As entradas chegam pela nota fiscal, e todo movimento fica no histórico.

  • Python
  • FastAPI
  • PL/SQL
  • React

Benefícios e RH

Vale-transporte e vale-alimentação calculados a partir das batidas de ponto, seguindo as regras da casa: férias, atestado, estagiário, admissão no meio do mês. Sincroniza com a plataforma de ponto todo dia e gera o arquivo que a folha de pagamento importa, comissões incluídas.

  • Python
  • APScheduler
  • React
  • Recharts

Telas do ERP no navegador

Rotinas do Winthor (TOTVS) refeitas na web para quem não precisa de uma licença do ERP: simulação de preço, impressão de pedido com QR code e código de barras, extrato de produto, priorização de expedição. A consulta segue o SQL que o próprio ERP executa, para o resultado bater com o original.

  • Oracle SQL
  • FastAPI
  • React

RF, app para coletores

App Android para os coletores de código de barras do armazém. Separar, conferir e receber mercadoria bipando item a item, gravando no ERP pela API do portal.

  • React Native
  • Expo
  • TypeScript

IA no dia a dia

Assistente de orçamentos por chat para a equipe de vendas, feito com LangGraph e a API do Claude. Servidores MCP dão aos assistentes de IA da TI acesso ao banco do ERP, somente leitura, e ao Pipefy.

  • LangGraph
  • Claude API
  • MCP
  • Python
