# mkeacs.github.io

Portfólio pessoal, publicado em https://mkeacs.github.io.

HTML, CSS e JavaScript puros, sem build. Para editar, mexa em `index.html` (textos em português), `assets/main.js` (textos em inglês, no objeto `EN`) e `assets/style.css`. O GitHub Pages publica sozinho a cada push na `main`.

Para ver localmente: `python -m http.server` na pasta e abrir http://localhost:8000.
